# 板のマスを切り出して、学習させるための道具

ホワイトボードの○×を機械に読ませるための土台。2026-09-09 に、実物の写真
（団体910280 の 9/6 男子リーグ、板2面）と、それに対応するアプリの記録を
突き合わせながら作った。

## 分かっていること（すべて実測）

### 大きな模型（Gemini 2.5 Flash）には荷が重い

| 1枚に写す人数 | マスの種類が合った割合 |
|---|---|
| 16人（板2面まるごと） | **25%** |
| 4人（1立ぶん） | **83%** |
| 1人 | **10/10 すべて一致** |

16人だと、列ごとに同じ並びを使い回す（見ずに型で埋める）。人数を絞ると
実際に見て答える。ただし**線の向き（＼か／か）は、どの粒度でも読めなかった**。

有料枠の模型（gemini-2.5-pro / 3.1-pro）は無料枠では使えない。

### 板は下から書き足される

団体910280 の板は、いちばん下が1立目だった。合計欄も下から
22→44→65→88→107 と増えている。1番の列を1マスずつ突き合わせると、
**下から読んだときだけ10マス全部が正解と一致**した。
取り違えると、その人の○×が丸ごと逆順になる。

### 罫線は使えない。印そのものを手がかりにする

ホワイトボードの罫線は薄く、写真では拾えない（しきい値を下げると
ネームプレートや数字を線と取り違える）。○×は濃く、規則正しく並んでいるので、
濃いかたまりを拾って、その並びから格子を復元する。

行の本数は分かっている（射数と、1マスが何射かで決まる）。分かっている本数の
等間隔を、いちばんよく合う位置に置く。印は割れたりくっついたりするので、
束ねるだけでは列によって10本になったり14本になったりした。

名札は色の枠に入っている。彩度の高い帯を見つけて、そこから下は見ない。

**実測：射手8列すべてを正しく取れた（小計・合計の数字の列は自動で外れる）。
10行×8列のうち76マスに印が在ることまで確かめた。**

### 札は自動で貼れる

写真と、それに対応するアプリの記録があれば、記録の○×から
「このマスは◎」と逆算して札を貼れる。手で札を付ける必要がない。
**80マスぶんの札付きデータを、1枚の写真から自動で作れた。**

目で見て確かめた（`docs/ocr-samples/ichiran.png`）。4種類ははっきり分かれており、
**模型が読めなかった線の向きも、切り出すと一目で分かる**。

### 見分け方をどこまで詰められたか

| やり方 | 当たり |
|---|---|
| 特徴4つ（輪・真ん中の墨・対角）を平均で見る | 51.3% |
| 近傍法（16×16の画、1枚抜き検証、k=3） | 63.8% |
| 丸の中身の形（塊か棒か）で見る | 65.0% → 設定を探して 77.5% |
| **中ほどの帯で、2つの対角の寄りを見る**（miwakeru.mjs） | **80.0%** |

いちばん良かったのは最後のやり方。札ごとの平均がはっきり分かれる。

| 札 | 外の輪 | ＼ | ／ |
|---|---|---|---|
| × | 0.35 | 0.199 | 0.272 |
| ◎ | 0.90 | 0.134 | 0.126 |
| 丸に＼ | 0.81 | **0.265** | 0.090 |
| 丸に／ | 0.80 | 0.095 | **0.239** |

◎は「2つの対角の差がほぼ無い」ことで見分ける。中り数だけなら 83.8%。
**1人あたりの的中数は、8人ぶんで合計11射のずれ（多くは±1）。**

ただし境目は同じ80マスで探した値なので、別の板ではこれより下がる。
「直せる下書き」としてなら使えるが、そのまま信じられる精度ではない。

## 使い方

```bash
# 格子が立つかを見る
node scripts/ocr-cells/shirabe-koushi.mjs 板.jpg

# マスを切り出して、記録から札を貼る（scripts/ocr-cells/kiridasu.mjs を部品として使う）
```

## これから要るもの

札付きデータは80マスしかない。写真が他に無いので、学習させても確かめる
ぶんが残らない（いまの80%も、同じ80マスで境目を探した値）。

現実的な道は2つ。

1. **直せる下書きとして出し、直されたぶんを札として貯める。**
   使ううちにデータが増える。ひと季節ぶん貯まれば学習に足りる。
2. **描いて作る。** 4種類とも形は単純なので、手書きのゆらぎを真似て
   描き起こせば数千枚は作れる。本物80枚と混ぜて学習させる。

どちらも、この切り出しの仕組みがそのまま土台になる。
