# 矢所記録機能の実装タスクリスト（作業手順書）

本タスクリストは、「矢所記録機能」の実装に向けて、具体的にどのファイルをどのように改修するかをステップバイステップでまとめたものです。進行状況に合わせてチェック（`[x]`）を入れて管理します。

## 1. 状態管理（Store）の拡張
- `[x]` **`JP_useScoreStore_174.js` の改修**
  - 初期状態にグローバル設定値を追加する
    - `enableArrowLocation: false` （矢所記録機能のON/OFF）
    - `arrowTargetType: 'kasumi36'` （的の種類：'kasumi36', 'hoshi36', 'hoshi24'）
  - 射手（archer）データの構造拡張
    - `arrowLocations: []` を各アーチャーのプロパティに追加（各射の座標データを `{x, y}` の形式で保持）
  - 新規アクションの追加
    - `setEnableArrowLocation(boolean)`
    - `setArrowTargetType(string)`
    - `updateArrowLocation(archerId, shotIndex, location)` （指定した射の矢所を更新、undo/redoのhistoryStackにも対応させる）

## 2. 設定画面のUI追加
- `[x]` **`JP_SettingsScreen_1023.js` の改修**
  - 「矢所の記録」セクションを新設
  - 矢所記録機能のON/OFFを切り替えるトグルスイッチ（Switch）の追加
  - ONの場合にのみ表示される「的の種類とサイズ」の選択UI（Pickerまたはボタンリスト）の追加
    - 選択肢：霞的（尺二:36cm）、星的（尺二:36cm）、星的（八寸:24cm）
    - ※的のビジュアルアイコンを添えて選択しやすくする

## 3. 矢所入力ポップアップ（新規コンポーネント）の作成
- `[x]` **`ArrowLocationPopover.js` （新規作成）**
  - 指定された座標（または画面中央）に展開するモーダルUIの実装
  - 右上に「×（閉じる）」ボタンの配置
  - 設定された的の種類 (`arrowTargetType`) に応じて的のSVG/画像を描画
  - タップイベントの座標取得と正規化（的の中心を(0,0)、半径を1とする座標計算）
  - 現在の記録（○/×）に基づくタップ領域の制限ロジック
    - ○の場合：的の半径（1.0）以内のみタップ許可
    - ×の場合：的の半径（1.0）より外側のみタップ許可
  - 既に記録されている座標がある場合は、該当射数（インデックス）の数字マーク（①、②など）をレンダリングする

## 4. 記録表セルの改修とポップアップ連動
- `[x]` **`JP_ScoreCell_596.js` の改修**
  - セルのタップ（`onPress`）処理の拡張
    - 通常の○/×トグル処理後、`enableArrowLocation` がONの場合は **0.5秒のタイマー** をセット
    - 0.5秒経過後に `ArrowLocationPopover` を開くコールバックを発火
  - セルの長押し（`onLongPress`）処理の追加
    - すでに記録がある場合、タイマーを待たずに即座にポップアップを開いて再編集できるようにする
  - ポップアップを表示する際、セル自身の画面上の座標を取得し、ポップアップ側に渡す（表示位置の最適化）

## 5. 履歴・分析画面での矢所表示
- `[x]` **`ArrowLocationView.js` （新規作成）**
  - 読み取り専用で的と矢所リストを描画する共通ビューコンポーネント
  - 複数の矢所座標を受け取り、それぞれ対応する射数のマーク（①、②等）を weの上にプロットする
- `[x]` **`JP_HistoryScreen_692.js` 等の履歴詳細系の改修**
  - 個人成績の詳細を表示するモーダルやセクションに `ArrowLocationView` を組み込む
- `[x]` **`JP_AnalysisScreen_1000.js` の改修**
  - 個人分析のタブ/画面において、選択した期間や立の矢所データを集約して `ArrowLocationView` に渡し、グルーピング傾向を視覚的に表示する
