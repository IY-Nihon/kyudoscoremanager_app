# 分析詳細グラフにおける途中交代・複数立ちデータの反映 - 実装計画

個人成績の分析詳細画面に表示される時系列グラフおよび詳細データにおいて、途中交代した射や、同一セッション内で複数の立ち（行）に入った際の記録が正しく反映されないバグを修正します。

## ユーザー確認事項
- グラフの集計ロジック (`Se` 関数) を、ランキング用集計ロジック (`xe` の算出) と同様に「セッション内のすべての射手行をループして該当メンバーの射を抽出する」方式に変更します。
- この変更により、グラフの点（日付や月）をタップした際、交代分や複数立ち分も合算された正しい的中率・的中の詳細が表示されるようになります。

---

## 提案される変更

### [MODIFY] [JP_AnalysisScreen_1000.js](file:///c:/Users/yutoi/Documents/kyudoscoremanager_app/src/JP_AnalysisScreen_1000.js)

#### 修正方針
1. `Se` 関数内の `o.archers.find` 処理を `o.archers.forEach` ループに変更します。
2. 各行（`r`）ごとに、その行の中で対象メンバーが引いた射数 (`i`) と的中数 (`s`) を計算します。
3. 1つの行の中で対象メンバーが引いた射が1射以上存在する場合のみ、その行のデータを `n[a].details` に追加します。
4. 4射ごとの立ちの結果分布（皆中、三中など）の集計についても、各行ごとにループを回して対象メンバーの4射セット（すべて該当メンバーの射で構成されているセット）を判定・カウントします。

## 検証計画

### 自動テスト
- `npx expo export --platform web` を実行し、ビルドがエラーなく正常終了することを確認します。

### 手動検証
1. **途中交代データの検証**:
   - 別のメンバーの立ち（行）に途中交代で参加したセッションにおいて、グラフ詳細画面で該当セッションの日付をタップした際、交代後に引いた射の成績が反映されていることを確認します。
2. **複数立ちデータの検証**:
   - 同一の練習セッション内で、自分が2つ以上の立ち（行）に参加しているデータにおいて、グラフ上に対象セッションの全投射数・的中数が合算されて集計されていることを確認します。
