# 分析詳細グラフにおける途中交代・複数立ちデータの反映 - 修正内容確認 (Walkthrough)

個人成績の分析詳細に表示される時系列グラフおよび詳細データにおいて、途中交代した射や同一セッション内で複数の立ち（行）に入った際の記録が正しく反映されない問題を解決しました。

## 1. 実施した変更内容

### 1.1. 設定画面における時系列集計ロジックの改善
- **対象ファイル**: [src/JP_AnalysisScreen_1000.js](file:///c:/Users/yutoi/Documents/kyudoscoremanager_app/src/JP_AnalysisScreen_1000.js)
- **変更内容**:
  - `Se` 関数内の `o.archers.find` 処理を `o.archers.forEach` ループに変更しました。
  - セッション内の最初の1行だけを取得していたロジックを、すべての行を走査する形に変更し、交代後のメンバー ID/名前、および2つ目以降の立ち（行）もすべて漏れなく集計するようにしました。
  - **同一セッション内データの合算表示**: 複数立ちや途中交代が同じセッション（同じ記録用紙）で行われた際、グラフの点をタップした詳細ポップアップにおいて、立ち（行）ごとに分かれて表示されるのではなく、セッション全体での合計射数と的中数に合算して「1つの詳細項目」として表示されるように改善しました。
  - 同様に、4射ごとの立ち結果分布（皆中、三中などの集計）についても、すべての行から対象メンバーが4射引いたセットを正しく抽出し、集計対象とするように修正しました。
