# 卒業生選択ドロップダウンの実装計画

記録表の射手選択モーダルにおいて、卒業生を期ごとに整理して選択できるように、アコーディオン形式のドロップダウンメニューを追加します。

## ユーザーレビューが必要な事項

- **UI構成**: 卒業生セクションを「メンバーを選択」セクションの下に追加します。
- **操作感**: 期のタイトルをタップすると、その期に属する卒業生が表示される形式（アコーディオン）を想定しています。

## 検証計画

### 手動確認事項
- 射手選択モーダルを開き、現役メンバーの下に「卒業生を選択」が表示されているか。
- 各期をタップした際に、その期の卒業生リストが正しく展開・閉じるか。
- 卒業生の名前をタップした際に、射手として正しく設定されるか。
- 検索フィルターが卒業生リストにも（必要に応じて）反映されるか、または独立して動作するかを確認。
