# ログイン画面のダークテーマ化と「矢と的」背景アニメーションの実装計画

本計画は、弓道記録アプリのログイン画面（`src/JP_LoginScreen_1036.js`）の背景に、指定されたHTML（`ai_studio_code (17).html`）から抽出した「矢と的」のアニメーションを統合し、画面全体を高品質なダークテーマ（#030508）へ適応させるものです。

## ユーザー確認事項

> [!NOTE]
> Webアプリとネイティブアプリ（iOS / Android）の両方で美しい動作とパフォーマンスを両立させるため、以下のハイブリッド設計を採用します。
> - **Web環境**: `Three.js` による完全な3Dアニメーション（元のHTMLと同じ甲矢・乙矢の自転・公転運動および落下する星屑）を実装。
> - **ネイティブ環境**: `react-native-svg` と `react-native-reanimated` を使用し、同心円の的と美しい矢のベクトル画をゆっくり回転・浮遊させるアニメーションを実装。これにより、重いWebViewやクラッシュリスクを回避し、ネイティブに最適化されたスムーズなアニメーションを提供します。

## 提案する変更内容

### ログイン画面のコンポーネント

#### [MODIFY] [JP_LoginScreen_1036.js](file:///c:/Users/yutoi/Documents/kyudoscoremanager_app/src/JP_LoginScreen_1036.js)

- **ダークテーマ対応のスタイル定義**:
  - `container` 背景色を `#030508` に変更。
  - `title`、`subtitle`、`label` などのテキストカラーを白（`#FFFFFF`）やゴールド（`#e5c184`）に変更。
  - `card`（入力フォームコンテナ）を半透明ダーク（`rgba(255, 255, 255, 0.04)`）かつ微細な境界線付きに変更し、ダークテーマと調和させます。
  - `inputWrapper` や `input` の文字色・境界線色を調整。
- **背景アニメーションコンポーネントの統合**:
  - WebとNativeそれぞれで動作する `KyudoBackgroundAnimation` を実装・インポートし、ログイン画面の最背面に絶対配置（`position: 'absolute', inset: 0, zIndex: -1`）で配置します。
