# 記録編集モーダルのスクロール対応計画

記録編集モーダルにおいて、入力項目（タイトル、メモ、タグ、出席管理など）が多い場合に画面に収まりきらず、スクロールもできない問題を修正します。

## ユーザー確認事項

> [!NOTE]
> 編集画面全体をスクロール可能にすることで、下部にある「変更を保存」ボタンや出席管理の項目へアクセスできるようにします。

## 提案する変更

### [Component: UI]

#### [MODIFY] [JP_EditSessionModal_694.js](file:///c:/Users/yutoi/Documents/kyudoscoremanager_app/src/JP_EditSessionModal_694.js)
- `ScrollView` コンポーネント (`default_297`) をインポートに追加します。
- モーダル内のメインコンテンツ部分を `ScrollView` でラップし、高さが溢れた場合にスクロールできるようにします。
- スクロール時でも「変更を保存」ボタンが押しやすいよう、レイアウトを調整します。

## 検証計画

### ブラウザテスト
- ブラウザツールを使用して、以下の手順を確認します：
    1. 管理者モードで履歴の詳細画面を開く。
    2. ハンバーガーメニューから「記録を編集」を選択。
    3. モーダルが表示された際、画面をスクロールして最下部の「変更を保存」ボタンまで到達できるか確認する。
    4. 特にメンバーが多い場合の「出席管理」セクションが正しくスクロールできるか確認する。
