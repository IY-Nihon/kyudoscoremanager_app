# 弓道スコアマネージャー AI拡張機能 実装計画 (Implementation Plan)

## 背景と目的
先ほど定義したAI拡張機能（自動操作、データの自動入力・編集、Google検索グラウンディング）を実際のコードベースへ段階的に導入するための詳細な実装手順と技術調査結果をまとめました。

## 技術調査結果
現在のソースコード（`App.js` や `JP_AIChatBot_1034.js` など）を解析した結果、以下の方法で実装可能であることが確認できました。

1. **Google Search Grounding（外部検索）**:
   * アプリ内に組み込まれているGemini SDKの設定（`tools` パラメータ）に、Google検索機能を許可するオプション（`{ googleSearch: {} }` 等）を追記するだけで有効化できる見込みです。
2. **ナビゲーション連携（アプリ自動操作）**:
   * `JP_AIChatBot_1034.js` はすでにナビゲーションツリー（`NavigationContainer`）の内部に配置されているため、React Navigation の `useNavigation` フックを呼び出すことで、AIから直接かつ安全に画面遷移（タブの切り替えなど）を実行できます。
3. **データ連携（自動入力・編集）**:
   * `JP_useScoreStore_174.js` に定義されている各種アクション（`addMember` など）を AIChatBot 側から呼び出すことができます。

> **実装の優先順位について**
> 3つの機能を一気に実装するとシステムが複雑になるため、まずは**リスクが低くすぐに効果を実感できる「①Google検索機能」と「②ナビゲーション連携」から先に実装（Phase 1）**し、動作確認が取れた後に「③データの自動入力・編集」を進めるのが安全ですが、いかがでしょうか？

## Verification Plan (検証計画)

実装完了後、以下の手順で動作を検証します。

### Manual Verification (手動確認)
1. **ナビゲーション検証**: チャット画面でAIに「設定画面を開いて」「メンバータブを見せて」などと送信し、バックグラウンドで正しく画面が切り替わることを確認。
2. **Google検索検証**: AIに「全日本弓道連盟の競技規則について教えて」「弓のメンテナンス方法は？」など専門的な質問をし、Web検索結果に基づいた最新の回答（出典リンク付き）が返ってくることを確認。
3. **（後日）データ編集検証**: AIに「部員を追加して」と指示し、確認用のアクションカードが表示され、「承認」を押した時のみデータが反映されることを確認。
