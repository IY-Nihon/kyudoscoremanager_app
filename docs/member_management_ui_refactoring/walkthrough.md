# UI修正 Walkthrough

メンバー管理機能の改善と、それに伴う各画面の整合性調整を完了しました。

## 1. メンバー管理画面 (`JP_MemberScreen_1022.js`)
- **現役生（0-4年）と卒業生（5年）の分離**: メインリストには現役生のみを表示し、卒業生はリスト下部のアコーディオン内に移動しました。
- **期別アコーディオン**: 卒業生を「期（termKi）」ごとにグループ化し、タップで開閉できるようにしました。
- **スタイル最適化**: アコーディオン用のスタイルを追加し、視認性を向上させました。

## 2. 分析画面 (`JP_AnalysisScreen_1000.js`)
- **トグルスイッチの復元**: 削除していた「卒業生を表示」スイッチを復元し、統計に含めるかどうかを選択できるように戻しました。
- **フィルタの整理**: 学年フィルタから「卒業生」オプションを削除し、現役生の分析に特化させました。

## 3. 出欠管理・的中記録画面 (`JP_EditSessionModal_694.js`, `JP_ArcherActionModal_689.js`)
- **ラベル表示の修正**:
  - `grade: 5` → **「卒業生」**
  - `grade: 0` → **「その他」**
  - `grade: 1-4` → **「○年生」**
- 的中記録時のメンバー選択リストでも、同様のセクション分けとラベル適用を行いました。
