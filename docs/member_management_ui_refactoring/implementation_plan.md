# メンバー管理 UI 刷新および整合性修正 実装計画

## 概要
メンバー管理における現役生と卒業生の区分を明確にし、関連する分析画面および出欠管理画面のUIとラベルを修正します。

## 修正対象
1. **メンバー管理画面 (`JP_MemberScreen_1022.js`)**
   - リストを現役生と卒業生で分離。
   - 卒業生を期ごとにグループ化してアコーディオン表示。
2. **分析画面 (`JP_AnalysisScreen_1000.js`)**
   - 「卒業生を表示」トグルスイッチの復元。
   - 学年フィルタの選択肢調整。
3. **出欠管理・的中記録 (`JP_EditSessionModal_694.js`, `JP_ArcherActionModal_689.js`)**
   - ラベル表示の不備修正（grade 5 → 卒業生, grade 0 → その他）。
   - セクション分けの整合性確保。
