# 出欠管理機能の実装完了報告

Kyudo Score Manager に、部員ごとの活動状況を把握・管理するための包括的な「出欠管理システム」を実装しました。

## 実装された主要機能

### 1. 出欠確認フローの統合
- **記録保存時の確認モーダル**: セッションの保存ボタンを押した際に、部員ごとの出欠（出席、遅刻、早退、欠席）を最終確認するステップを追加しました。
- **Firestore 連携**: 各セッションデータに `attendance` フィールドを持たせ、クラウド上で一元管理されるようにしました。

### 2. 出欠統計・管理画面 (`AttendanceScreen.js`)
- **統計表示**: 
  - 選択した期間（月間・年度・すべて）における出席率を自動計算。
- **個人詳細モーダル**: 
  - メンバーをタップすることで、その期間のすべての練習日とその日の出欠状況をリスト形式で確認可能。
- **正規練習日の管理**:
  - 月間グリッドカレンダー上で日付をタップするだけで、その日の練習有無を設定可能。
  - 曜日ヘッダー（日〜土）に対応。
  - **AI日程解析**: Gemini 1.5 Flash を活用し、練習日程が記載された PDF から自動的に日付を抽出して登録する機能を搭載。
    - **プレビュー機能**: 解析された日付を保存前にリストで確認・検証できます。
    - **Webブラウザ対応**: ブラウザ版でも PDF のアップロードと解析が可能です。
    - **リアルタイム・フィードバック**: 解析の進捗状況（読み込み中、AI解析中など）が画面に表示されます。

### 3. デザインと操作性
- **メンバー画面との統一**: 氏名や学年の表示スタイルを、既存のメンバー管理画面と完全に一致させました（色付きドット、太字名、期・学年表示）。
- **プレミアムな外観**: 出欠状況に合わせたカラーバッジや、視認性の高いカレンダーレイアウトを採用しました。

## 使用方法

1. **出欠を確認する**: 記録画面で練習を終了し「保存」を押すと、出欠確認画面が開きます。
2. **統計を見る**: ボトムタブの「出欠」から、部員ごとの参加率を確認できます。
3. **詳細を見る**: 統計リストのメンバーをタップすると、その人の具体的な参加履歴が表示されます。
4. **練習日を設定する**: 「練習日設定」タブに切り替え、カレンダー上で練習日を指定します。
