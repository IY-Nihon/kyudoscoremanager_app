# 出欠管理機能の安定化（AI日付抽出とカレンダー表示の修正）

出欠管理画面におけるAIの日付抽出精度を向上させ、カレンダーの表示崩れを修正する。

## 課題
- **AIの日付誤認**: PDFから日付を抽出する際、年情報を誤って解析し、カレンダーに反映されない。
- **カレンダーのズレ**: 月の開始曜日の計算結果に基づいて挿入される「空セル」にスタイルが当たっておらず、表示が崩れている。

## 提案する変更

### AIプロンプトの動的指定
- `AttendanceScreen.js` の `handlePickPDF` において、カレンダーで選択されている `${selectedYear}` と `${selectedMonth}` をAIに渡し、PDFに年月の記載がない場合の補完基準とする。

### カレンダーレイアウトの修正
- `styles` に `calendarCellEmpty` を追加し、`width: '14.28%'`（1/7）を設定することで、カレンダーのグリッド位置を正常化する。
