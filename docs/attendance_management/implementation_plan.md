# 実装計画: 出欠管理機能の統合

## 目的
弓道的中管理アプリに、部員の練習参加状況を可視化し、管理者の事務負担を軽減するための出欠管理機能を導入する。

## 提案される変更

### 1. 出欠確認フローの追加
- 記録保存時に `AttendanceCheckModal` を表示。
- `JP_useScoreStore_174.js` の `saveSession` を拡張し出欠データを保存。

### 2. 出欠統計画面の実装
- `AttendanceScreen.js` を新規作成。
- 月間・年度・全期間での統計計算。
- カレンダー形式での正規練習日管理。
- Gemini API による PDF 日程解析。

### 3. 個人詳細表示
- 期間内の全練習日と出欠状況をリスト化して表示。
