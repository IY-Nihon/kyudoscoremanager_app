# AIチャット機能 精度向上のための調査レポート（修正版）

現在のAIチャットの実装（`src/JP_AIChatBot_1034.js`）を調査し、回答精度（特にアプリの操作方法や的中情報からのアドバイス）を飛躍的に向上させるための改善案をまとめました。ユーザーからのフィードバックを反映し、より高度なデータ連携と、内部構造まで踏み込んだ詳細なコンテキストの付与を目指します。

---

## 1. 現状の課題と改善方針

### A. 的中データの渡し方と人数の制約
*   **現状:** 各部員の「全期間を通した平均的中率」と「皆中回数」のみを計算し、さらに**上位30名**に絞ってシステムプロンプトに渡しています。
*   **改善方針:**
    1.  **スライス（最大数）制限の撤廃:** Geminiモデル（Flash/Pro）は非常に長いコンテキストを処理できるため、30名の制限をなくし、現役・卒業生含めた全員の概要データを渡します。
    2.  **渡すデータを大幅に拡充:** 全期間の平均だけでなく、直近のトレンドや出席率など、多角的なデータを渡すことで分析精度を劇的に向上させます。

### B. アプリの操作・仕様に関する知識不足
*   **現状:** システムプロンプトには「アプリの使い方に関する質問に答えてください」という指示のみで、具体的な機能や内部の仕様が共有されていません。
*   **改善方針:** アプリのすべてのタブ（記録、履歴、分析、メンバー、設定、出欠管理）の機能と、**内部のアーキテクチャ（データベース構造や進級処理の仕組み）**を網羅した詳細なマニュアルをAIの知識として埋め込みます。

### C. Function Calling（関数呼び出し）の導入
*   **方針:** 概要データだけでは補いきれない「特定の個人の詳細な過去データ」や「特定の期間の練習履歴」などを、AIが自律的に必要に応じて取得できる仕組み（Function Calling）を実装します。

---

## 2. 具体的な実装プラン

### 提案1: Function Calling を活用した動的データ取得（本命機能）
すべての詳細データを一度にテキスト化するのではなく、AIが自ら「このデータが欲しい」と関数を呼び出せるようにします。

*   **実装する関数の例:**
    *   `getMemberStats(memberId)`: 指定した選手の「初矢の的中率」「立順（大前・中・落）ごとの成績」「羽分けの割合」「直近1ヶ月の成績推移」などの超詳細スタッツを取得する。
    *   `getRecentSessions(limit)`: 直近10回分、あるいは指定した月の全体練習データ（誰が参加して全体的中率がどうだったか）を取得する。

### 提案2: 常に渡す「概要データ」の拡張
プロンプトの最初に渡す全員分のデータを「もっと多く」します。
*   **追加する計算データ項目:**
    *   直近のトレンド（直近5回・10回練習での的中率）
    *   月間の中り（今月・先月の的中率比較）
    *   最近の練習参加頻度（出席率）

### 提案3: 内部アーキテクチャを含む極めて詳細な「マニュアル」の埋め込み
以下のレベルで詳細なマニュアルテキストをシステムプロンプトに埋め込みます。AIがアプリの構造を完全に理解した上でユーザーをサポートできるようになります。

```text
【弓道的中管理アプリ 完全マニュアル（内部仕様含む）】

■ [システムアーキテクチャ・データ仕様]
・データベース: Firebase Firestoreを使用し、データのリアルタイム同期とオフラインキャッシュ（IndexedDB永続化）を実現しています。通信環境が悪い道場でもアプリは動作します。
・状態管理: Zustand を使用し、クライアント側で高速に画面をレンダリングします。
・データ構造: メンバーは「UUID（id）」で一意に管理され、練習記録（セッション）内の「archers」配列にスコア（○/×）が保存されます。

■ [記録] タブの操作
・機能: 日々の練習セッションを作成し、的中（○/×）や出欠を記録します。
・立ちの設定: 参加メンバーを選択して「立ち」を作成します。現役生（1〜4年生）と卒業生は分けて表示されます。
・記録方法: メンバー名の横にある的アイコンをタップして「○（的中）」と「×（失中）」を記録します。

■ [履歴] タブの操作
・機能: 過去のすべての練習セッションの確認・修正・削除を行います。
・記録の修正: 日付ごとのセッションをタップすると詳細が開きます。選手の「○/×」ボタンを再度タップすることで即座に上書き保存されます。
・セッションの削除: セッション項目を長押し、またはスワイプすることで練習データそのものを削除できます。

■ [分析] タブの操作
・機能: 記録されたデータを元にグラフ等で傾向を確認します。
・全体分析: 部全体の月別的中率推移などを確認できます。
・個人分析: メンバーを選択すると、その個人の「日別の成績推移」「立順ごとの成績」「初矢の的中率」「皆中回数」が確認できます。

■ [出欠管理] タブの操作
・機能: 公式の練習日を設定し、部員の出席状況をカレンダーや統計で確認します。
・正規練習日: 管理者がカレンダー上で日付をタップすると「正規練習日」として設定されます。
・統計: 指定した期間（月間・年間）の各メンバーの出席率が自動計算され、一覧で表示されます。出欠状況は履歴タブから直接修正可能です。

■ [メンバー] タブの操作
・機能: 部員データの管理を行います。
・追加: 「新規追加（＋）」から、名前、学年（1〜5）、性別を入力して追加します。
・卒業生の扱い: 学年が「5」以上のメンバーは、UI上「卒業生」として扱われます。

■ [設定] タブの操作
・進級処理: 「全メンバーの学年を上げる」機能（年度替わり用）。実行すると、4年生は内部的に「grade: 5」となり、過去の記録を保持したまま「卒業生」としてシステムに残り続けます。削除されることはありません。
・パスワード/アカウント: パスワードを忘れた場合は、団体管理者に直接問い合わせる必要があります。AIはセキュリティ上パスワードを開示しません。
```
