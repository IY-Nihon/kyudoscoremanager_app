# 管理者モード編集時のエラー修正計画

管理者モードで記録編集画面（ハンバーガーメニューから「記録を編集」）を開こうとすると、React のキー重複エラーが発生してクラッシュする問題を修正します。

## ユーザー確認事項

> [!NOTE]
> この修正は UI の表示不具合とクラッシュの解消のみを目的としており、既存のデータには影響を与えません。

## 問題の特定

調査の結果、`src/JP_EditSessionModal_694.js` 内の「出席管理」セクションで、リストレンダリングの `key` 属性に JSX 要素（オブジェクト）が誤って渡されていることが判明しました。これにより React はすべての要素のキーを `[object Object]` と認識し、重複エラーを発生させていました。

## 提案する変更

### [Component: UI]

#### [MODIFY] [JP_EditSessionModal_694.js](file:///c:/Users/yutoi/Documents/kyudoscoremanager_app/src/JP_EditSessionModal_694.js)
- 84行目付近の `key` 属性の指定を、JSX オブジェクトから `member.id` に修正します。

## 検証計画

### ブラウザテスト
- ブラウザツールを使用して、以下の手順を確認します：
    1. 履歴画面を開く。
    2. 管理者モードを有効にする。
    3. 任意の記録の詳細画面を開く。
    4. ハンバーガーメニュー（メニューアイコン）をタップする。
    5. 「記録を編集」をタップし、エラーが発生せずに編集モーダルが表示されることを確認する。
