# 矢所記録の設定UI復旧の実装計画

設定画面（[JP_SettingsScreen_1023.js](file:///c:/Users/yutoi/Documents/kyudoscoremanager_app/src/JP_SettingsScreen_1023.js)）において消失してしまっている「矢所記録の有効化トグル」および「使用する的の種類」の選択UIを復旧します。

## ユーザーレビュー要求事項

> [!IMPORTANT]
> 以前のパッチスクリプトでは的の種類が `kasumi` と `hoshi` の2択となっていましたが、ストアおよびポップアップの実際の実装に合わせ、`kasumi36`（霞的 尺二寸）、`hoshi36`（星的 尺二寸）、`hoshi24`（星的 八寸）の3つの的種類を正しく選択できるようにパッチ内容を最適化します。
> また、一般メンバー（個人用ログインモード）でもこの設定を閲覧・変更できるように `'member'!==V&&` の権限制御を外した状態で復旧させます。

### 1. 設定画面コンポーネントの修正

#### [MODIFY] [JP_SettingsScreen_1023.js](file:///c:/Users/yutoi/Documents/kyudoscoremanager_app/src/JP_SettingsScreen_1023.js)

## 復旧作業手順（スクリプト実行）
手動での文字置き換えはトランスパイル後の1行ファイルに対して行うのが困難なため、Node.jsによる専用のパッチスクリプトを作成・実行し、確実にコードを挿入します。

### 自動テスト / 検証計画
- パッチ適用後、Expoの開発サーバー（またはWeb環境）で設定画面を開き、以下の点を確認します。
  1. 「設定」タブに「矢所の記録」セクションが表示されていること。
  2. 「矢所の記録機能を有効化」トグルをONにすると、的種類の選択肢が表示されること。
  3. 的の種類（霞的、星的、星的(八寸)）の切り替えが機能し、トグルを切り替えても選択状態がストアに永続化されること。
  4. 記録画面（RecordScreen）で的中（○/×）を入力した際に、設定した的の種類に基づいた矢所ポップアップモーダルが自動的に開くこと。
