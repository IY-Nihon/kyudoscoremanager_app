# ロード画面のタイトルおよび画像変更の実装計画

弓道的中管理アプリの起動時ロード画面（ローディング画面）を、本来の「弓道」のコンセプトに沿った美しいデザインへアップデートします。

## 変更の概要

### 1. タイトル表記の変更
- 英語で表記されていた `"Archery Record"` を、日本語の正式名称である **`"弓道的中管理"`** へ変更します。

### 2. 画像（アプリアイコン）の表示
- 現在は青い角丸の四角形が表示されているだけの状態から、アセット内にある高精細な弓道アプリアイコン画像（`kyudo_icon.png`）を表示するデザインに変更します。
- 画像の下に、スマートで控えめなローディング用ブルーインジケーターを配置し、現在読み込み中であることを視覚的にわかりやすく表現します。

## 影響を受けるコンポーネント

### 1. LoadingScreen ([JP_LoadingScreen_1037.js](file:///c:/Users/yutoi/Documents/kyudoscoremanager_app/src/JP_LoadingScreen_1037.js))
- **表示内容のアップデート**: 青い四角形を廃止し、`Image` コンポーネントを用いて `kyudo_icon.png` を描画。
- **テキストのアップデート**: `Archery Record` ➔ `弓道的中管理`
- **インジケーターの配置調整**: アイコンの下部に青色の `ActivityIndicator` を美しく配置。
- **スタイル（StyleSheet）の修正**: `logoWrapper`、`logoImage`、`loaderWrapper` などの新しいスタイル定義を追加。

## 検証計画

### 手動確認
- アプリをローカル環境で起動、またはビルドして、起動時のロード画面が意図通りに変更されていることを確認します。
- 同期ログ（デバッグログ）が壊れずに正常に表示されるかを確認します。

### 本番デプロイ
- ビルドして Firebase Hosting にデプロイし、実機スマートフォン等で表示を確認します。
