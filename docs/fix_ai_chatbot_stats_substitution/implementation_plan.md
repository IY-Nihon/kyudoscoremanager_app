# AIチャットボット集計ロジックの交代メンバー対応化（実装計画）

AIチャットボット（[JP_AIChatBot_1034.js](file:///c:/Users/yutoi/Documents/kyudoscoremanager_app/src/JP_AIChatBot_1034.js)）のデータ分析ツール（Function Calling用の関数）において、メンバーの途中交代（`substitutions`）が反映されておらず、的中率の集計にズレが生じていたバグを修正します。

## ユーザーレビュー要求事項

> [!IMPORTANT]
> 交代ロジックを反映させるため、AIチャットボット内の以下の3つのツールをすべて修正します。
> 1. `getAllMembersStats` (全部員の統計情報)
> 2. `getDetailedMemberStats` (特定の部員の詳細統計、大前・落の集計、矢数ごとの集計)
> 3. `getSessionsByDate` (特定日付/期間のセッションにおける個人の的中集計)
> 
> 集計方法は、アプリ内の通常の分析画面で使用されているロジック（`JP_AnalysisScreen_1000.js`）と同じ「交代情報が登録されているインデックス以降の的中を交代後のメンバーの成績として加算する」アルゴリズムに統一します。

## 提案する変更内容

### 1. AIチャットボット内部ツールの修正

#### [MODIFY] [JP_AIChatBot_1034.js](file:///c:/Users/yutoi/Documents/kyudoscoremanager_app/src/JP_AIChatBot_1034.js)

1. **`getAllMembersStats` の修正**:
   - `sessions` の各行で交代マッピング `substitutions` と `substitutionIds` をループ内で参照し、各射が実際に引いた射手の成績としてカウントされるよう修正。
2. **`getDetailedMemberStats` の修正**:
   - 各射のインデックスごとの的中、および大前（1行目の射手）や落（最終行の射手）の判定においても交代処理を組み込み、実際にその位置で引いた射手の成績としてカウントされるよう修正。
3. **`getSessionsByDate` (の `memberName` 指定時) の修正**:
   - セッションデータから該当選手の的中を抜き出す際、交代により途中参加・離脱した射の情報を正しく抽出するように修正。
