# アプリアイコン、ログイン画面、OGP説明文の更新完了

ご依頼いただいた追加の修正を完了し、本番環境（Firebase Hosting）へデプロイしました。

## 実施した変更内容

1. **共有時説明文（OGP description）の更新**
   - デプロイスクリプトを修正し、SNS共有時の説明文を以下の通りに変更しました。
     - 変更前：「弓道の的中記録と出欠を管理するアプリです。」
     - 変更後：「**団体**弓道の的中記録と出欠を管理するアプリです。」
2. **ログイン画面のアイコン変更**
   - ログイン画面中央に表示されていた統計チャートのアイコンを、ご指定の弓道アイコン（`assets/icon.png`）に差し替えました。
   - アイコンの角を丸く（borderRadius: 20）設定し、アプリ全体のデザインに馴染むように調整しています。

## 確認方法

1. [https://kyudoscoremanager.web.app](https://kyudoscoremanager.web.app) にアクセスしてください。
   - ※既にログイン済みの場合は、一旦ログアウトするかシークレットウィンドウで開くとログイン画面を確認できます。
2. ログイン画面中央に新しいアイコンが表示されていることを確認してください。
3. LINE等でURLを共有した際の説明文が「団体弓道の...」に変わっていることを確認してください。（※キャッシュの関係で反映に時間がかかる場合があります）

## 開発環境について
- 今後の開発は `C:\Users\yutoi\Documents\kyudoscoremanager_app` で行ってください。
- デプロイ時は `npm run deploy:web` を実行してください。（※Firebaseのプロジェクト設定エラーが出る場合は `firebase deploy --only hosting --project kyudoscoremanager` を直接実行してください）
