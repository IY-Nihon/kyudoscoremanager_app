# チャットボット・個人的中分析の改善 - 実装計画 (Implementation Plan)

チャットボットの利便性向上、個人的中分析画面における集計バグの修正、および他のメンバーとの多角的な比較機能の追加に向けた実装計画です。

---

## 1. 提案する変更内容

### 1.1. 【チャットボット】アイコンのドラッグ移動安定化と複数部員登録のバグ修正
- **対象ファイル**: [JP_AIChatBot_1034.js](file:///c:/Users/yutoi/Documents/kyudoscoremanager_app/src/JP_AIChatBot_1034.js)
- **修正内容**:
  1. **メッセージID管理への移行**:
     - チャットボットが提示する「データの追加提案（承認カード）」の管理を、配列インデックスから「一意なメッセージID (`msgId`)」に変更します。
     - これにより、複数人を一度に追加しようとした際、1人目を承認したタイミングでメッセージ配列のインデックスがズレてしまい、他のカードが承認できなくなったりバグを発生させたりする問題を完全に防止します。
  2. **PanResponder の安定化**:
     - Web環境を含む各種プラットフォームでのドラッグ操作の追従性を向上させるため、PanResponderのレスポンダー確保条件（`onMoveShouldSetPanResponder`）の閾値を微調整し、誤判定を防止します。

### 1.2. 【個人的中分析】グラフ点タップ時の集計漏れバグの修正
- **対象ファイル**: [JP_AnalysisScreen_1000.js](file:///c:/Users/yutoi/Documents/kyudoscoremanager_app/src/JP_AnalysisScreen_1000.js)
- **修正内容**:
  1. **シャドウイングバグの解消**:
     - グラフデータ集計関数 `Se` 内の交代情報走査ループ `for (const e of d)` において、ループ変数名 `e` が引数の `e`（メンバーID）をシャドウイング（上書き）していた問題を修正します。
     - 変数名を `subIdx` に変更することで、IDでのマッチング判定 `(e && c === e)` が正常に機能するようにし、途中交代や別立ちで登録されたデータがすべてグラフに正しく反映されるようにします。
  2. **名前の表記揺れ吸収**:
     - 名前でマッチング判定を行う際、スペース of の有無（全角・半角）を `replace(/\s/g, '')` を用いて除外した上で一致比較するように修正し、集計漏れを防止します。

### 1.3. 【詳細遷移】グラフ点タップからの履歴画面への遷移と該当メンバーへのスクロール
- **対象ファイル**:
  - [JP_AnalysisScreen_1000.js](file:///c:/Users/yutoi/Documents/kyudoscoremanager_app/src/JP_AnalysisScreen_1000.js)
  - [JP_HistoryScreen_692.js](file:///c:/Users/yutoi/Documents/kyudoscoremanager_app/src/JP_HistoryScreen_692.js)
  - [JP_useScoreStore_174.js](file:///c:/Users/yutoi/Documents/kyudoscoremanager_app/src/JP_useScoreStore_174.js)
- **修正内容**:
  1. **遷移ステートの追加**:
     - `useScoreStore` に、遷移時にフォーカスを当てるメンバーIDを保持する `focusedMemberId` を追加します。
  2. **詳細カードからの遷移**:
     - `AnalysisScreen` のグラフ点タップ時に表示される詳細セッション情報をタップ可能（`TouchableOpacity`）にします。
     - タップ時に、対象の `sessionId` とタップした `memberId` (または本人ID) を `focusedMemberId` として Store にセットし、`navigation.navigate('履歴')` で履歴タブへ遷移させます。
  3. **履歴詳細画面での自動スクロール**:
     - `HistoryScreen` 内で、選択されたセッション詳細が表示された際、`focusedMemberId` が設定されていれば、該当するアーチャー列のインデックスを特定します。
     - 横スクロール用Ref（`Re` および `Oe`）に対し、該当列の位置（`列のインデックス * 列の幅`）を計算して `scrollTo` を実行し、自動でその人の位置までスクロールするように実装します。

### 1.4. 【比較機能】他のメンバーとの比較機能（グラフ重ね合わせ・矢所横並べ・的中率縦並び）
- **対象ファイル**: [JP_AnalysisScreen_1000.js](file:///c:/Users/yutoi/Documents/kyudoscoremanager_app/src/JP_AnalysisScreen_1000.js)
- **修正内容**:
  1. **比較用UIの追加**:
     - 個人分析詳細モーダル内に「他のメンバーと比較」ボタンを設置し、他の部員（現役・卒業生）を選択できるPicker modalを追加します。
  2. **重ね合わせグラフの描画**:
     - 比較対象メンバーが選ばれた際、同様に `Se` 関数を用いてそのメンバーの推移データを作成し、SVGグラフ内に緑色などの別の色のラインを重ねて描画します。
  3. **矢所の横並べ表示**:
     - 矢所の傾向表示において、比較対象がいる場合は `flexDirection: 'row'` のレイアウトで、本人用の的と比較対象用の的を左右（あるいは上下）に2つ並べて表示します。
  4. **立ち順（射順）別的中率の縦並び表示**:
     - 1〜4射目別の的中率を、本人と比較対象のバーを並べて比較できるように対比レイアウトに拡張します。
